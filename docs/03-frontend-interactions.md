# 03. 화면 동작과 사용자 상호작용

## 1. 운세 요청 플로우
1. 사용자가 폼에 모든 정보를 입력하고 [운세 보기] 버튼 클릭
2. JavaScript(`script.js`)에서 입력값 유효성 검사 (빈 값 체크)
3. 유효한 경우, 버튼 상태를 '로딩 중'으로 변경
4. 백엔드(Node.js)의 `/api/fortune` 엔드포인트로 `POST` 요청 (입력 데이터 JSON 포함)
5. 응답이 성공하면 결과 영역에 AI 운세 텍스트 표시. 실패 시 사용자 친화적 오류 메시지 표시(예: "우주의 기운을 불러오는 데 실패했습니다.")
6. 로딩 상태 해제

## 2. 피드백 전송 플로우
1. 하단 피드백 입력창에 텍스트 작성 후 [전송] 클릭
2. 빈 값 체크 후, 백엔드 `/api/feedback` 엔드포인트로 `POST` 요청
3. 요청 완료 시 입력창 초기화 및 피드백 리스트 새로고침

## 3. 피드백 리스트 불러오기
1. 페이지 최초 로드 시 백엔드 `/api/feedback` 엔드포인트로 `GET` 요청
2. 반환받은 데이터를 최신순으로 화면 리스트에 렌더링

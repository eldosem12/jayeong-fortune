# 02. UI/UX 구현 기준

## 1. 전체 테마 (image_3c95fe.jpg 참조)
- **배경**: 우주를 연상시키는 딥 다크 블랙 (`#0a0a0a` 등) 배경. 필요 시 미세한 별빛 질감 처리.
- **폰트**: 깔끔한 Sans-serif 폰트 (Pretendard 등). 주 텍스트는 흰색(`#ffffff`) 적용.
- **레이아웃**: 중앙 정렬 위주의 비대칭 화면 구성.

## 2. 주요 화면 구성
1. **타이틀 영역**: '자영샘 돈으로 하는 오늘의 운세' 타이틀 (굵은 타이포그래피)
2. **입력 폼 영역**:
   - 이름 (Text)
   - 성별 (Radio 또는 Select)
   - 생년월일 (Date)
   - 양력/음력 (Radio)
   - 태어난 시 (Select)
   - [운세 보기] 버튼 (흰색 배경에 검은색 텍스트 등 대비가 뚜렷한 스타일)
3. **결과 노출 영역**: 운세 결과 텍스트가 표시되는 모달 또는 카드 영역 (기본은 숨김)
4. **피드백 영역 (화면 하단)**:
   - 피드백 입력 Textarea + [전송] 버튼
   - 전송된 피드백이 실시간(또는 새로고침 시) 최신순으로 나열되는 리스트 영역

## 3. 반응형 및 접근성
- 모바일 화면에서도 폼 입력과 피드백 리스트가 깨지지 않도록 Flex/Grid 기반 설계
- 오류 시 폼 하단에 빨간색 경고 텍스트 표시
